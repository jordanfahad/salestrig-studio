# SS-002: LinkedIn multipart video upload

## 1. Summary

Video uploads now validate the full instruction list, send each inclusive byte range to its own URL, and finalize with the returned token and ordered ETags.
Both real provider posting paths are covered by 41 isolated tests, including failure stops, readiness polling, and image/PDF single-PUT regressions.
The new tests pass; full-suite, lint, TypeScript and build gates remain blocked by failures reproduced on the unchanged `salestrig-studio` baseline.

- `libraries/nestjs-libraries/src/integrations/social/linkedin.provider.ts`: use the validated plan, exact buffer subarrays, non-empty ETags, and `uploadToken ?? ''`.
- `libraries/nestjs-libraries/src/integrations/social/linkedin.video-upload.ts`: small pure validator/part planner. Reject missing parts, invalid HTTP URLs, non-integer ranges, gaps, overlaps, out-of-order/out-of-bounds ranges and incomplete coverage before any PUT. - `.agent-bus/outbox/SS-002.md`: this handoff.

Branch: `codex/SS-002`. Baseline: `44357242` (`salestrig-studio`). The working tree was clean and the branch had no commits beyond baseline at task start.
